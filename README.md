# 👨‍👩‍👧‍👦 KEUANGAN KELUARGA - PWA Web App

Aplikasi pembukuan kas kolaboratif suami dan istri berbasis Web & Progressive Web App (PWA) dengan sinkronisasi realtime menggunakan Supabase.

## 🚀 Fitur Utama
- **Realtime Sync**: Sinkronisasi instan pencatatan antara ponsel Suami & Istri via Supabase.
- **PWA Ready**: Dapat diinstal langsung ke layar utama Android & iOS tanpa App Store.
- **Pemisahan Kas**: Gaji pokok, non-gaji (bonus/usaha), pengeluaran belanja, dan brankas tabungan.
- **Curved Bottom Bar**: Navigasi bawah modern dengan kurva cekung dinamis dan floating active indicator.
- **Nota & Struk**: Lampiran foto bukti transaksi belanja langsung di setiap catatan.

## 📦 Cara Pasang ke GitHub Pages
1. Buat repository baru di GitHub (pilih *Public*).
2. Unggah seluruh file (`index.html`, `manifest.json`, `sw.js`, `.gitignore`, `README.md`).
3. Buka menu **Settings** > **Pages**.
4. Di bagian *Branch*, pilih `main` dan folder `/(root)`, lalu klik **Save**.
5. Akses aplikasi Anda via URL: `https://USERNAME.github.io/NAMA-REPO/`
